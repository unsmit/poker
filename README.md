# Poker Statistical Tracker

A Java-based Texas Hold'em odds calculator that uses Monte Carlo simulation to estimate win, loss, and tie probabilities based on a player's hand, community cards, and number of players.

## Features

- Monte Carlo simulation for poker hand probabilities
- Seven-card Texas Hold'em hand evaluation and tiebreakers
- Support for known community cards and multiple opponents
- Object-oriented design for cards, decks, players, and game state
- Multithreaded simulations across CPU cores
- Reduced average simulation computation time by 16% in benchmark testing

## Running the Project

Compile and run using:

make run
